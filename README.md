# El Gran Arsenal

Catálogo interactivo en español con ideas de objetos custom para un servidor de
Minecraft Java 1.21.x.

## Abrir en localhost

No requiere instalar dependencias:

```bash
python3 -m http.server 4173
```

Después abre [http://localhost:4173](http://localhost:4173).

Incluye filtros por categoría, etapa, método técnico y dificultad; fichas
detalladas, favoritos persistentes, selección aleatoria y exportación de ideas.
